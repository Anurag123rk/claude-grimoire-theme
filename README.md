# Grimoire — a monochrome theme for Claude

A quiet, anime-inspired monochrome theme for the Claude desktop and mobile apps.
Pure AMOLED black (`#000000`) background, ink-gray panels, paper-white text, and
muted accent colors. Behind the chat: a faint hand-drawn ink clover in the corner,
one soft brush stroke, and a few slow drifting ash motes. Original art, kept subtle.

## Install

At the prompt of a Claude Code session:

```
/plugin install custom-theme --marketplace Anurag123rk/claude-grimoire-theme
```

Answer `y` to add the marketplace, then pick a scope.

From a shell:

```bash
claude plugin install custom-theme --marketplace Anurag123rk/claude-grimoire-theme
```

## Use

- `/grimoire` or `/grimoire on` — turn the theme on
- `/grimoire off` — turn it off (remembered across sessions)

Dark-only by design. Themes draw in the desktop and mobile apps; the terminal
and editors keep their own look. Motion stops when reduced motion is on.
